# 资源占位清单

所有文件名都可以按实际截图调整，但调整后要同步修改 pipeline JSON 中的 `template` 路径。

| 占位资源 | 用途 |
| --- | --- |
| `通用/返回按钮.png` | 页面返回 |
| `通用/关闭按钮.png` | 关闭活动或奖励弹窗 |
| `通用/主界面标志.png` | 确认已回到主界面 |
| `启动/进入游戏.png` | 启动页进入游戏 |
| `育成/开始育成.png` | 进入育成模式 |
| `育成/训练按钮.png` | 训练选项入口 |
| `育成/比赛按钮.png` | 比赛或目标比赛入口 |
| `育成/回合结束.png` | 回合结算后的继续按钮 |
| `日常/签到入口.png` | 每日签到入口 |
| `日常/一键领取.png` | 任务一键领取 |

OCR 文案目前使用 `TODO_` 前缀。建议先用 MaaDebugger 或截图工具确认分辨率，再把稳定、唯一的按钮文字填入 `expected`。
